07 / Unity VR · Procedural Visualization

Fineo, Translated Universe

An award-winning Unity VR and data-visualization installation that maps scientific data into harmonograph-inspired procedural forms, spatial composition, and immersive interaction.

Director / Technical ArtistUnityVRC#ProcessingProcedural MappingGrand Prize

System design

01 · Data mapping

Mapped periodic-table variables such as atomic radius, group, and electronegativity into parameters of harmonograph-inspired equations.

02 · Procedural generation

Converted numerical relationships into moving points, trails, and spatial forms instead of pre-rendered visual assets.

03 · World construction

Built a larger speculative spatial system where generated forms could combine into molecule- and planet-like structures.

04 · Unity VR

Transferred the procedural visual language into an immersive Unity environment with navigable spatial composition.

05 · Exhibition delivery

Prepared the work for public presentation through VR and display-based installation contexts.

06 · Recognition

Received the Grand Prize at the 16th Kookmin University Art & Design Exhibition.

For Gaucho Game Lab, Fineo is evidence that I can move from an abstract mathematical rule to a complete real-time interactive visual system inside a game engine.
