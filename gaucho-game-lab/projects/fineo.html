Fineo, Translated Universe

An award-winning real-time system that translates scientific data into harmonograph-inspired procedural motion, spatial form, and an immersive Unity VR environment.

Director / Technical ArtistUnityVRC#ProcessingProcedural MappingScientific Data

Core idea

The work began with a translation problem: how can numerical properties from the periodic table become a generative visual language rather than a conventional chart? I mapped variables such as atomic radius, group, and electronegativity into parameters of harmonograph-inspired equations, then developed the resulting trajectories into a navigable real-time world.

Inputperiodic-table variables
Translationdata → equation parameters
Outputpoints · trails · spatial structures
RuntimeUnity VR immersive environment

How the procedural system was developed

01 · Select source variables

Identified scientific variables whose ranges could drive distinct visual behavior, including atomic radius, periodic-table group, and electronegativity.

02 · Normalize the data

Converted source values into usable parameter ranges so one property would not dominate the entire visual system simply because of its numerical scale.

03 · Map data to equations

Assigned the normalized values to harmonograph-inspired parameters, turning scientific differences into changes in frequency, motion, phase, and spatial trajectory.

04 · Prototype in Processing

Used Processing to iterate quickly on the data-to-motion relationship and inspect whether the mapped variables produced visually distinct but coherent forms.

05 · Build procedural forms

Converted equation output into moving points, trails, and accumulating spatial structures rather than relying on pre-rendered animation.

06 · Establish compositional rules

Developed a larger visual grammar in which generated forms could combine into molecule- and planet-like structures while remaining driven by the underlying system.

07 · Port the logic to Unity

Transferred the procedural logic into a real-time Unity context so the system could be rendered, staged, and explored interactively.

08 · Construct the 3D world

Placed generated forms into a larger spatial hierarchy, using scale and composition to move from abstract data visualization toward an inhabitable environment.

09 · VR scale and navigation

Evaluated the work immersively, adjusting scale and spatial relationships so forms that worked on a monitor still read when experienced from inside the scene.

10 · Exhibition build

Prepared the real-time system for public presentation through VR and display-based installation contexts, emphasizing repeatable operation rather than a one-off development demo.

Why procedural instead of pre-rendered

The visual form remains traceable to a rule system. Changes to source data or mapping logic can propagate through the visualization without rebuilding every asset manually.

Technical-art contribution

The project connects abstract mathematical rules, visual iteration, code, real-time rendering, spatial composition, and VR. It demonstrates a workflow that moves from an algorithmic prototype into an authored interactive experience.

Fineo received the Grand Prize at the 16th Kookmin University Art & Design Exhibition. For Gaucho Game Lab, its relevance is the process: turning an abstract rule into a complete interactive system inside a game engine.
