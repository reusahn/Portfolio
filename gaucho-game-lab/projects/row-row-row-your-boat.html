Pipeline and technical contribution

01 · Identity build

Created ten MetaHuman identities from real-person source material and normalized each character for consistent production behavior.

02 · Character correction

Handled recurring skin, eye, teeth, and groom issues so the cast could read as a coherent ensemble rather than ten unrelated test assets.

03 · Head/body integration

Resolved head-body setup conflicts and animation artifacts while maintaining facial performance timing.

04 · Facial performance

Integrated and edited Live Link Face performance ranges, including incomplete or mismatched capture segments.

05 · Multi-character timing

Built canon-like timing across the cast and validated overlapping performances in a dense 5×2 arrangement.

06 · Lighting and delivery

Prepared morning, sunset, and night looks and supported final installation delivery for Melbourne Town Hall.

This is direct evidence of production-scale character work: repeated asset integration, synchronization, visual consistency, and technical troubleshooting across a cast rather than a single hero character.
