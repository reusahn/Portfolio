08 / Unity VR · AI NPC · Meta Quest 3

Escape Metro

A surreal Unity VR escape game combining spatial puzzle solving, real-time AI NPC conversation, CC4 character integration, runtime dialogue systems, and standalone Meta Quest delivery.

Director / Technical ArtistUnity URPMeta Quest 3ChatGPT APICC4Runtime DialogueStandalone Optimization

Gameplay and systems

XR interaction

Built the experience in Unity for Meta Quest 3 with spatial navigation, puzzle progression, and room-scale interaction as the core gameplay loop.

AI NPC conversation

Integrated a ChatGPT-driven dialogue layer so conversation was part of progression rather than a separate chatbot feature.

Character implementation

Used Character Creator assets and runtime facial/animation systems to support an in-world AI guard and other interactive characters.

Standalone delivery

Prepared the experience for standalone Quest hardware, including shader, lighting, asset, and runtime decisions appropriate for a public-facing VR build.

Production pipeline

01 · Character setup

Prepared CC4 characters for Unity, connected animation and blendshape-based facial behavior, and validated them in the XR runtime.

02 · Dialogue integration

Connected player conversation to AI responses and in-game state so dialogue could influence the escape-game progression.

03 · Voice interaction

Combined voice input and generated character responses to make the NPC interaction feel spatial and immediate inside VR.

04 · Gameplay logic

Connected puzzle, door, and navigation logic with the conversational layer instead of treating AI as a detached demo.

05 · Optimization

Reduced rendering and runtime cost for Meta Quest 3 through practical standalone-VR constraints and repeated device testing.

06 · Public deployment

Delivered the experience for a public showcase at the Seongsu KAIA pop-up store.

Standalone Quest 3 delivery required balancing character rendering, dialogue systems, XR interaction, and device-side performance in one repeatable public build.
