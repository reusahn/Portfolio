Gang Se-hwang Digital Human

A full historical-character pipeline from reconstruction and facial rigging through hair, cloth, engine integration, interaction logic, and museum kiosk deployment.

Director / Technical ArtistUnity HDRPZBrush / ZWrap / Maya~256 Facial BlendshapesPythonXGen / Hair CardsMarvelous DesignerC#

Character pipeline

01 · Reconstruction

Built the historical character through sculpting, wrapping, retopology, UV, and deformation-ready cleanup.

02 · Facial system

Created an ARKit-oriented facial setup with approximately 256 blendshapes and modified a Python importer for iPhone facial CSV data.

03 · Hair and garments

Prepared XGen/hair-card solutions and Marvelous Designer garments, balancing realism with real-time constraints.

04 · Animation delivery

Integrated facial and body animation, Alembic/Timeline elements, and timing controls for a public-facing presentation.

05 · Interaction

Implemented Unity-side C# for interaction, camera behavior, sequencing, and presentation logic.

06 · Museum deployment

Validated the work as a kiosk-style installation rather than only a studio render, with attention to stability and repeatable playback.

Visual evidence

This project connects character art, technical animation, scripting, facial-data tooling, cloth/hair workflows, and Unity deployment in one production chain.
