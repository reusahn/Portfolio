Unlike a MetaHuman-only workflow, this character required building and connecting the full stack: identity reconstruction, deformation, facial data, grooming, costume, engine lookdev, interaction code, and public deployment.

Full character production process

01 · Historical reconstruction

Interpreted portrait references into a believable 3D identity, using sculptural decisions to translate a limited historical image source into a complete head and face.

02 · Sculpt and wrap

Developed the high-resolution form in ZBrush and used wrapping as part of the process for moving the likeness toward a controlled production topology.

03 · Retopology and UV

Prepared Maya topology and UVs that could support facial deformation, material work, and predictable export into the real-time character pipeline.

04 · Rig and deformation support

Prepared the character for body and facial animation, checking deformation-sensitive areas before building the larger facial-shape library.

05 · Facial blendshape system

Built approximately 256 custom facial blendshapes from ARKit-style foundations to give the character enough range for captured facial performance.

06 · Facial-data tooling

Modified a Python importer so iPhone facial CSV data could be translated into the project's facial system instead of manually rebuilding each performance.

07 · Hair and beard

Developed grooming with XGen and real-time hair-card solutions, including secondary treatment for beard and facial hair presentation.

08 · Hanbok garments

Prepared the historical clothing through Marvelous Designer and the downstream character pipeline, balancing costume silhouette with real-time presentation needs.

09 · Unity HDRP lookdev

Tuned skin, eye, hair, cloth, lighting, and material response together in Unity HDRP so the character held up as a real-time digital human rather than a DCC render.

10 · Runtime application

Implemented C# logic for interaction, camera behavior, animation sequencing, and presentation control around the character.

11 · Installation validation

Tested repeatable playback and public-facing behavior as a kiosk installation, where stability and clear reset behavior mattered alongside visual quality.

12 · Live composite

Integrated the final character into the presentation context, including camera-composite output used to connect the digital human with the public-facing installation.

Process evidence

Technical art problems

  • Historical likeness from limited portrait evidence
  • Production topology that could support a large facial-shape library
  • Bridging iPhone facial data into a custom rig through Python
  • Real-time hair, beard, skin, eye, and cloth presentation
  • Character animation plus application-level C# logic
  • Stable repeatable museum playback

Why it matters for game production

This case shows full-stack character ownership. I can move from character construction and deformation into runtime materials, animation data, scripting, interaction, and deployment without treating those stages as unrelated departments.
