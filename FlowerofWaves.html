핵심 전제 — Dimensional Ontology
𝔹(x,y,z,τ) → 현무암 = 4차원 저장소
τ = 주체성(Subjectivity) = 시간의 모든 흔적
파도에 띄움 → τ = 0 → 𝔹(x,y,z)
원 텍스처 = 4D → 2D 단면 : 𝒞(u,v)
현무암은 생성 이후 지금까지 모든 시간 정보를 담은 4차원 객체다. τ(타우)는 주체성·역사·시간 축을 의미한다. 파도에 띄우는 행위는 τ를 외부(파도)로 이전시켜 현무암에서 주체성을 삭제하고, 순수한 3D 위치 데이터만 남긴다. 표면의 원형 구멍들은 이 4D 정보가 2D로 찍힌 단면이다.
현무암 — Basalt 4D Object
𝔹 (x, y, z, τ)
τ = ∫₀ᵀ φ(t) dt 　　　// 탄생부터 현재까지 누적 흔적
𝒞ᵢ(u,v) = proj₂D(τ) 　// 원 텍스처 = 4D의 2D 단면
𝔹(x,y,z,τ) : 현무암 4D 좌표계. (x,y,z)는 공간, τ는 누적 시간·역사·주체성
𝒞ᵢ(u,v) : 표면의 i번째 원 — 4D 역사가 2D 평면에 투영된 흔적
파도의 문법 — Wave Grammar (Wave Particle 기반)
W(x, y, t) = A · sin(kx - ωt + φ) · e^(-λr)
Δp(t) = p(t) - p(t-1) 　// 오브제의 프레임별 변위
τ_wave = {v, θ, r, φ} 　// 파도가 흡수한 주체성
W(x,y,t) : SIGGRAPH 2007 Wave Particle 기반 파동 함수. A=진폭, k=파수, ω=각진동수, λ=감쇠계수
Δp(t) : 파도 위 오브제의 매 프레임 이동 벡터 = 꽃의 움직임 원형
τ_wave : 파도가 현무암으로부터 이전받은 주체성 (속도·방향·반지름·위상)
꽃의 알고리즘 — Flower Algorithm
F(u,v,t) = 𝒞ᵢ(u,v) + Σₙ αₙ · Δp(t-n) · e^(-λn)
α(η) = { 0 η=0 → 대칭꽃, η>0 η=const → 비대칭꽃 }
꽃 크기 = |𝒞ᵢ| + |Δp|,　 밀도 = Σn,　 방향 = arg(Δp),　 색 = f(|Δp|, Σn)
F(u,v,t) : 현무암 원 위치(𝒞ᵢ)에서 파도 잔상(Δp)이 겹쳐 꽃이 피는 함수
η (노이즈) : η=0 → 완전 대칭 꽃, η=const(>0) → 비대칭 자연 꽃
λ (감쇠) : 잔상이 시간에 따라 옅어지는 속도. 클수록 잔상이 빨리 사라짐
Σn (겹침) : 잔상이 많을수록 꽃의 밀도가 높아지고 색이 짙어짐
무용수 모션캡처 — Human Impact
H(x,y,z,t) → impulse(r) = I₀ · e^(-r²/σ²)
F′(u,v,t) = F(u,v,t) + impulse(‖(u,v) - H_xy‖)
H(x,y,z,t) : 무용수 모션캡처 3D 좌표
impulse(r) : 무용수 위치에서 거리 r에 따라 감쇠하는 충격파 — 꽃밭 흔들림
F′ : 인간의 움직임이 더해진 최종 꽃 상태. σ가 클수록 영향 반경이 넓어짐

CONCEPT 01
주체성 (τ)
현무암에 내재된 시간의 총합. 파도에 띄우는 순간 파도로 이전됨. 아리스토텔레스의 목적인(Telos)에 해당하는 개념 — 사과가 스스로 의지로 떨어지는 것처럼.
CONCEPT 02
파도의 문법
이전받은 τ를 물리 운동으로 표현하는 규칙. Wave Particle의 발상처럼, 파도는 외부가 아닌 입자 스스로가 만든다 — 자연이 기술에 능동적으로 적응하는 방식.
CONCEPT 03
꽃의 알고리즘
원 텍스처(2D 단면) 위에 파도 잔상(Δp)이 겹쳐 꽃이 피는 구조. 노이즈 η가 0이면 대칭, 0 이상이면 비대칭 — 움직임이 형태를 결정하는 순간.
CONCEPT 04
인간의 충격
무용수의 모션캡처가 가우시안 충격파로 꽃밭에 영향을 줌. 인간의 데이터가 디지털 자연으로 들어왔을 때 발생하는 변화 — 4D→인간→자연의 순환.

Di(x,t) = aᵢ · Wᵢ(|x − xᵢ(t)|) · Π(|x − xᵢ(t)| / 2rᵢ) — SIGGRAPH 2007
논문 핵심 공식 — Yuksel, House, Keyser 2007
Di(x,t) = aᵢ /2 · (cos(π|x−xᵢ(t)|/rᵢ) +1) · Π(|x−xᵢ(t)|/2rᵢ)
xᵢ(t) = 파도 위 구(球)의 시간 t에서의 위치
→ 이 구의 매 프레임 위치가 겹쳐 잔상이 됨 → 그것이 꽃의 알고리즘 원점
