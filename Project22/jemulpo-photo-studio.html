Jemulpo Photo Studio

A live visitor-portrait installation combining Unity, computer vision, segmentation, image processing, archiving, and external display delivery at Incheon Metropolitan Museum.

ROLETechnical Director
ENGINEUnity / C#
CV / MLPython · OpenCV · Barracuda
VENUEIncheon Metropolitan Museum
PIPELINE

Audience input became a complete exhibition output.

The system had to process a live visitor, generate a result, preserve it, and update the gallery display without manual intervention.

01Face Capture
02OpenCV Detection
03Barracuda Segmentation
04Style / Shader Processing
05Auto Archive
06TCP Display Wall
IMPLEMENTATION

Real-time application engineering inside a technical-art workflow.

CAPTURE

Face detection that included hair and head context

OpenCV DNN detection was extended through landmark-based post-processing so the transformed portrait could include more than the central facial crop.

SEGMENTATION

Runtime subject isolation

Unity Barracuda separated visitors from the background so the generated portrait could be placed into historically styled layouts.

VISUAL SYSTEM

Custom style and shader treatment

Face-swap output was combined with watercolor / pointillist-style processing designed around early Korean magazine-print aesthetics.

DELIVERY

Archive and external display handoff

Generated portraits were timestamped and saved automatically, then sent over TCP to an external display wall for a continuously updating exhibition gallery.
