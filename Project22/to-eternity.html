To Eternity

A public installation at Asia Culture Center that recognizes a visitor's flower-offering gesture and transforms their silhouette into a live mosaic made from archival photographs of the Gwangju Democratization Movement.

ENGINEUnity / C#
INPUTAzure Kinect · OpenCV

IMPLEMENTATION

Technical decisions were tied to audience behavior and exhibition reliability.

TRACKING

Real-time body and depth data

Azure Kinect SDK supplied depth, body-index and joint-coordinate data used to analyze the participant's upper-body pose.

GESTURE LOGIC

Sustained pose rather than a single-frame trigger

The flower-offering gesture was classified from arm and hand vectors and required sustained confidence before the visual event was triggered.

GRAPHICS

GPU-based archival composition

Approximately 300 documentary images were prepared for the installation, with shader-based transparency, luminance mapping and timed fade behavior used for the live mosaic.

DISPLAY

Unity + TouchDesigner projection workflow

The final composite was synchronized into a large wall projection so interaction, graphics and physical presentation behaved as one installation system.

NEX / MOTION FIT

Evidence for motion-driven interactive software and real-time feedback.

INPUT → OUTPUT

Sensor data became controllable visual behavior

The project connected physical audience input to real-time graphics through explicit detection thresholds and runtime logic.

SHADERS

Graphics logic was implemented in the runtime pipeline

GPU compositing and timing behavior demonstrate technical-art work at the intersection of code, shaders and final presentation.

DEPLOYMENT

Designed for a public institution

The application had to function as an installed experience rather than a workstation-only prototype or pre-rendered demo.
