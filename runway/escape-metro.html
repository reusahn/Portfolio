03 — SELECTED RESEARCH-LED PROTOTYPE

Escape Metro

Conversation is no longer a separate interface. It is part of the world the player has to escape.

YEAR2024
MY ROLEDirector · Technical Artist
PROJECT CONTEXTSeongsu KAIA Pop-up Store, Seoul
TOOLS / MEDIUMUnity · Virtual Reality · ChatGPT API · Interactive Game Systems
ORIGINAL PROJECT VIDEO · VIMEOVIDEO DEMONSTRATION / DIRECTED WORK
01 / THE IDEA

Can an AI conversation feel like part of a place rather than an application layered on top of it?

Escape Metro is a surreal VR escape game set in an uncanny subway system. Players move through the environment, solve puzzles, and speak with an AI-powered in-world character as they search for an exit. Built in Unity and presented in a public pop-up setting, the project uses conversation as a spatial and narrative device.

02 / EXPERIENCE

What people see, do, and experience

Players enter a subway world whose familiar architecture no longer follows ordinary logic. They explore enclosed platforms and passages while searching for clues and an exit.

A ChatGPT-powered character provides an opportunity for real-time dialogue inside the VR setting. The conversation becomes one of the ways the player understands the world and its rules.

The experience joins puzzle progression, environmental staging, and dialogue. The AI character is encountered as part of the fiction, not as a generic assistant outside it.

03 / MY CONTRIBUTION

From concept to implementation

I directed and technically developed the Unity VR experience, designing the visual situation and implementing interactions required for spatial exploration and puzzle progression.

I integrated the ChatGPT API into an in-game conversational character, connecting an external language-model service to the timing and context of a VR experience.

The project was presented at the Seongsu KAIA pop-up store, so the interaction had to be understandable to participants encountering the work as a short public experience.

05 / CREATIVE JUDGMENT

Why these choices mattered

I chose a subway because it is immediately legible to a player but can become surreal with small deviations. This creates an intuitive starting point for an experimental interactive story.

The central design decision was to embed dialogue in the escape experience. A language model was a component of a larger game system—not a claim that I developed a proprietary AI agent model or a general world simulator.

WHAT THIS PROJECT MAKES TANGIBLE

Escape Metro turns a language-model capability into a situated encounter. It is an example of using existing AI systems to explore new interaction patterns through environment, player agency, and storytelling.
