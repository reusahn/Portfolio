02 / MULTIMODAL INPUT + VR EXECUTION

Shininho / Jooan - Real-Time VR Character Runtime

An end-to-end real-time character case showing how independently captured geometry and performance streams become one interactive Unreal runtime. Jooan is the VR/cinematic extension of the Shininho digital-human production.

GeometryScan-derived digital human

Maya cleanup, Wrap correspondence, MetaHuman-compatible topology, textures, eyes, and final character setup.

BodyOptiTrack / Motive

Primary body performance captured and operated by me; difficult sections were retaken or manually reconstructed.

FaceRokoko + iPhone / MetaHuman workflows

Independent facial performance was captured and synchronized with body performance in Unreal.

RuntimeSequencer assembly

Body and face were retargeted/baked separately, assembled in Unreal, and reviewed as a final real-time performance.

01 / INGEST

Multiple input streams

Body, hand, facial and scan-derived data originate in different systems and require consistent timing and identity.

02 / CLEAN

Repair unreliable data

MotionBuilder whole-take cleanup and Maya detail repair handle spikes, floor contact, and missing motion.

03 / RETARGET

Normalize for engine

HumanIK / Unreal retargeting and bake convert performance into stable engine-ready animation.

04 / EXECUTE

Review in real time

Sequencer assembles character state, lighting, effects and presentation for interactive review.

JOOAN / RED HILL - VR EXTENSION

The same character, re-staged for real-time VR

The Shininho production character was moved into an Unreal VR context where viewer motion, spatial staging, lighting and effects had to work under headset constraints.

  • Adjusted viewer/camera speed after informal headset testing to reduce discomfort.
  • Used lighting, gaze direction and character motion to guide attention.
  • Built dusk presentation with HDRI + Skylight.
  • Added hand-attached Niagara ribbon effects and coordinated final timing in Sequencer.
