Escape Metro

A surreal VR escape game built as a playable Unity runtime, combining navigation, interaction logic, character animation, player voice, conversational AI, audio, and standalone-headset constraints.

A complete VR runtime

Escape Metro was structured around player agency inside a navigable subway world. The player moves through the environment, solves spatial problems, and communicates with an in-world AI character as part of progression.

Technical responsibilities

  • Built and integrated the Unity XR runtime and interaction flow in C#.
  • Prepared NPC character assets for the Unity character pipeline.
  • Integrated facial expressions and blendshape-driven lip sync with Animator-driven behavior.
  • Connected player voice input to speech-to-text and conversational AI response.
  • Integrated the soundscape through FMOD and Unity Audio Mixer.
  • Adjusted shaders and baked lighting with standalone Meta Quest performance in mind.
Environment + Character Assets ↓ Unity XR Runtime ↓ Player Navigation / Interaction / Voice ↓ NPC Dialogue + Animation State ↓ Puzzle / Progression Logic ↓ Standalone Headset Experience

Engineering relevance

The project required multiple runtime systems to cooperate under headset constraints: input, character state, conversation, audio, animation, rendering, and progression. It is representative of how I work across feature implementation, integration, debugging, and target-device iteration.
