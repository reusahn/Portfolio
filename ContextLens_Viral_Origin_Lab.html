How this search works

Images are rendered from each synthetic clip, sampled at several time positions, and compared using multi-region perceptual descriptors. Candidate frames must align in time.

Experiment evaluation

BOUNDARIES

Matching is computed from pixels. Source-family IDs are kept for post-analysis evaluation only. The algorithm does not crawl Instagram, run vPDQ, or use a Meta API key.
