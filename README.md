- **[SplatStream Lab](https://github.com/reusahn/splatstream-lab)**  
  3D Gaussian Splatting compression and rate-distortion experiments using pruning, FP16/INT8 quantization, compact payload accounting, CUDA rendering, and held-out PSNR / SSIM / LPIPS evaluation.
