INTERACTIVE BROWSER PROTOTYPE / GAME DESIGN STUDY

Two forces. One seed.

Two different inputs control the same seed. Player 01 generates lift; Player 02 steers. Coordinate both to navigate obstacles and reach the goal. This is a playable local mechanics prototype, not an online multiplayer game.

PLAYING

01 / Player A — Lift

Hold Space (or the lift button) for upward force. Release to allow gravity to pull the seed down.

02 / Player B — Steer

Left / Right arrows (or buttons) create horizontal wind. Momentum remains after input stops.

03 / Shared outcome

Stay between obstacles and enter the shelter ring. Contact with a wall or the ground ends the attempt.

Implementation scope: This runnable browser sandbox tests two-input game feel, movement, collision, goal state and retries. Network transport, server authority, two independent clients and online release management are separate Unity development milestones.
