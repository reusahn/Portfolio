AI + 3D WORKFLOW

AI for exploration. 3D for control.

My AI practice is useful to visualization because it accelerates visual search without giving up controllability. I use generated outputs as reference / concept material, then bring selected directions into real-time and DCC workflows where composition, geometry, materials, lighting, performance, and camera can be deliberately authored.

WORKING METHOD

Storyboards and previz are part of the technical pipeline.

Because my background includes filmmaking and technical art, I treat visualization as both an image problem and a communication problem: what needs to be understood, from which angle, under which light, in which sequence, and at what level of fidelity?

01Frame

Brief, design intent, references, story.

02Previsualize

Sketch, storyboard, layout, camera.

03Build

Asset / character / environment pipeline.

04Lookdev

Materials, lighting, shaders, CMF-adjacent surface judgment.

05Iterate

Real-time review, technical debugging, direction changes.

06Deliver

Hero shot, animation, interactive / immersive output.

ABOUT

Technical visualization with a filmmaker's eye.

My practice moves across film, XR, digital humans, interactive installations, and real-time graphics.
