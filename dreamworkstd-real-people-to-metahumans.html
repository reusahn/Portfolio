Project Task

Convert 10 real people into reviewable MetaHuman characters

The task was to take real participant references and produce a consistent set of digital humans that could be reviewed, compared, and prepared for real-time use. The work was less about making one hero character and more about building a repeatable process that could hold up across ten different people.

Production Problem

  • Each participant arrived with different reference quality, facial structure, lighting conditions, and available data.
  • Likeness is subjective, so the process needed a review structure: what changed, why it changed, and what still needed artist feedback.
  • Without data wrangling and naming rules, the project would quickly become ten disconnected character files instead of one controlled production pipeline.

Constraints

  • Ten subjects needed consistent setup quality, even when input references were uneven.
  • The artist needed to compare identity and presence, not debug missing files or inconsistent character states.
  • The final characters had to be prepared as real-time assets rather than only static likeness studies.

TD Solution

I built a standardized character-prep workflow: shared folder structure, clear subject IDs, reference boards, likeness notes, a repeated MetaHuman setup sequence, a group QA pass, and a final handoff format. The goal was to make every participant pass through the same pipeline so the artist could review differences in identity rather than differences in file organization.

Implementation Breakdown

Step 01

Reference Intake & Naming

Collected scan / photo / expression references into a consistent folder structure. Each subject was assigned a trackable ID so every reference, setup file, screenshot, and review output stayed connected.

Step 02

Reference Normalization

Built comparison boards for front, side, three-quarter, silhouette, facial proportions, and expression cues. This gave the MetaHuman setup a concrete likeness target instead of relying on memory.

Step 03

Base MetaHuman Setup

Created an initial MetaHuman for each participant, matching large facial structure first: head shape, jaw, cheekbones, nose bridge, eye spacing, mouth width, and overall facial rhythm.

Step 04

Identity Iteration

Compared the character against the reference board, logged the biggest likeness mismatches, and adjusted the character in passes rather than changing everything at once.

Step 05

Group Consistency QA

Reviewed all ten characters together for scale, age readability, material response, hair / silhouette consistency, and whether the set felt like one production package.

Step 06

Real-Time Prep & Handoff

Prepared final review states for UE5 / MetaHuman use, including organized screenshots, character files, notes, and a clean handoff structure for artist feedback.

Debugging / Iteration

Uneven reference dataBuilt a normalized reference board so each subject could still be reviewed with the same criteria.
Subjective likeness feedbackSeparated likeness into specific categories: silhouette, facial proportions, eye / nose / mouth spacing, material tone, and age impression.
Scale drift across charactersChecked the ten characters as a group instead of only reviewing each file in isolation.
Review confusionKept subject IDs, folders, screenshots, and notes consistent so feedback could point to the right asset quickly.
Real-time readinessPrepared the characters with downstream UE5 review in mind instead of stopping at a static MetaHuman look.
