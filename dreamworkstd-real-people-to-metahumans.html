Production Problem

Ten real participants needed to be converted into digital characters with consistent preparation quality. The input data varied from subject to subject, but the output had to feel like one controlled production system: organized, reviewable, and repeatable.

Ideation / TD Approach

I built the workflow around standardization and review. Instead of treating each participant as a separate custom task, I used a consistent folder structure, naming logic, likeness notes, setup sequence, and QA pass so all ten characters could move through the same production pipeline.

Workflow

Step 01

Data Intake

Collected and organized scan / photo / reference material for each participant into consistent folders and naming rules.

Step 02

Reference Normalization

Compared face structure, silhouette, proportion, and expression references so each character had clear likeness targets.

Step 03

MetaHuman Setup

Created MetaHuman characters while keeping reference notes visible during iteration and review.

Step 04

Consistency / QA Pass

Checked all ten characters as a group for scale, material response, identity match, and production consistency.

Step 05

Real-Time Prep & Handoff

Prepared characters for downstream UE5 review, artist feedback, and real-time use.

My TD Responsibilities

Data WranglingOrganized participant data so character preparation stayed trackable and repeatable across ten subjects.
Workflow StandardizationUsed the same setup and review structure for every character instead of inventing a new process each time.
Character SetupConverted real participants into MetaHuman-ready characters with identity matching in mind.
QA / ConsistencyReviewed the group for scale, likeness quality, material response, and production readability.
Artist SupportPrepared assets so the artist could compare identity and presence without debugging technical files.
