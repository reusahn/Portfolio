Photo Studio

A public-facing portrait system that joined Unity, Python, computer vision, runtime image processing, archiving, and external display delivery into one repeatable exhibition workflow.

SYSTEM OVERVIEW

One visitor interaction, multiple software boundaries.

The technical problem was not a single shader or CV model. The installation had to capture a person, interpret the image, generate a stylized portrait, archive the result, and hand it to another display system without requiring an operator to manually move files between tools.

01 / CAPTURE

Visitor-facing Unity application

Unity handled the public interaction layer, camera flow, state changes, and the timing of the portrait experience.

02 / VISION

Detection and segmentation

OpenCV-based face detection and Unity Barracuda person segmentation separated the visitor from the background and prepared the portrait for style processing.

03 / IMAGE PIPELINE

Custom visual processing

Custom image-processing and shader stages transformed the portrait toward the visual language of early twentieth-century Korean magazine imagery while preserving recognizable visitor features.

04 / DELIVERY

Archiving + external display

Finished portraits were automatically saved in timestamped folders and sent through TCP to an external display wall, where results entered a continuously updated exhibition loop.

PIPELINE

Designed as a repeatable content flow.

Each stage had a defined responsibility so failures could be isolated and the visitor experience could keep moving.

01 Capture

Acquire visitor portrait and initialize interaction state.

02 Detect

Locate face / head region and validate source image.

03 Segment

Separate subject from background with Barracuda.

04 Process

Apply custom portrait / shader treatment.

05 Archive

Save outputs automatically with stable naming.

06 Publish

Send result over TCP to the exhibition display.

WHY THIS MATTERS FOR TECHNICAL ART

Artist-facing systems are production systems.

Jemulpo is useful evidence of the less visible side of technical art: translating an artistic concept into a reliable workflow that spans engine code, image processing, machine-learning inference, file management, and another display application.

I treated the visual result and the operational pipeline as the same problem. The system only succeeded if the images looked right, the visitor interaction stayed understandable, files were generated consistently, and downstream display delivery happened without manual intervention.
