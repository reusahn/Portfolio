02 / USER INPUT · MATERIAL STATE

Graffiti Freedom.

A direct-manipulation mechanic in Unity VR: a player sprays paint, the world stores the mark in a dynamic texture, and the surface visibly changes. This project explores feedback as a persistent consequence of player input.

ROLETechnical ArtistENGINEUnity / VRFOCUSC# · Particles · RenderTexture · Shaders

Existing VR project — player spray-painting surfaces in the environment

01 / PROBLEM & OWNERSHIP

A design problem translated into a runtime system.

The distinction between creative objective and technical contribution is central to this case.

Design / production challenge

A spray effect that disappears after a frame feels decorative; a player tool should make the surface itself change. The system needed to translate freehand motion and particle collisions into stable visual information attached to geometry.

My technical contribution

I built the interactive spray feedback and connected hit locations with a dynamic RenderTexture mask consumed by the wall material. Input, collision, texture accumulation and display remain distinct stages that can be inspected independently.

02 / IMPLEMENTATION

How the feature works.

Concrete subsystems and boundaries, not only a list of software tools.

Player expression

The controller-driven spray mechanic lets users directly mark a world surface.

Immediate visual feedback

Particles communicate the direction and spread of paint during use.

Accumulated surface state

Collision coordinates update a RenderTexture so paint can remain visible throughout the active experience.

Shader-driven presentation

The surface shader reads the evolving mask rather than switching between prepainted textures.

VR input→Spray particles→Surface hit / UV→RenderTexture→Surface shader
03 / TECHNICAL DESIGN

Decisions that make iteration possible.

Each technical decision supports clarity, performance, or cross-disciplinary change.

Why a texture state?

A writable mask preserves the user's gesture on the mesh and provides a clean separation between interaction and presentation.

Why separate particle and paint?

Particles provide short-lived feedback, while the render target holds longer-lived changes to the world.

What would I tune for game feel?

Spray cone, hit spread, contact feedback and wall-material response can be evaluated separately.
