Project Task

Turn live performance into usable real-time character animation

The task was to capture performer movement and deliver animation files that could be used downstream by artists. The important TD work was not just recording motion, but creating a clean path from performer calibration to source data, cleanup, retargeting, character validation, and reviewable delivery.

Production Problem

  • Raw mocap data is never automatically production-ready: marker loss, jitter, incorrect contact, skeleton scale, and joint orientation can all break the performance.
  • The target character does not move exactly like the performer skeleton, so the transfer needed validation rather than a simple file conversion.
  • Artists needed readable performance outputs, not a folder of raw data that required technical troubleshooting.

Constraints

  • Capture sessions move quickly, so take naming and notes needed to be clear from the start.
  • Performance intention had to survive cleanup and retargeting.
  • Animation needed to be checked for real-time playback issues such as feet sliding, hip offsets, joint pops, and body-weight readability.

TD Solution

I structured the mocap process as a production pipeline: prepare the capture session, track takes, clean problematic data, retarget onto the target rig, run animation validation, and deliver files with review notes. The goal was to reduce ambiguity between capture, animation cleanup, and artist review.

Implementation Breakdown

Step 01

Capture Prep

Prepared performer calibration, take naming, movement requirements, and the review plan before recording so the session created usable data from the beginning.

Step 02

On-Set Capture

Captured performance while tracking usable takes, capture issues, timing notes, and movements that would need extra cleanup later.

Step 03

Raw Data Review

Reviewed takes for marker loss, jitter, missing contact, inconsistent body orientation, and performance moments worth preserving.

Step 04

Cleanup Pass

Cleaned motion data and corrected technical noise before retargeting, prioritizing performance clarity rather than over-smoothing the body.

Step 05

Retargeting

Mapped motion onto the target character rig and checked skeleton scale, joint behavior, shoulders, hips, feet contact, and body weight.

Step 06

Validation & Handoff

Exported reviewable animation outputs and prepared playback captures / notes so the director and artists could evaluate performance instead of debugging files.

Debugging / Iteration

Marker loss / jitterReviewed noisy sections and cleaned the data before retargeting to avoid transferring capture errors into the character rig.
Skeleton mismatchChecked scale, joint orientation, limb length, and neutral pose differences between performer data and target rig.
Foot slidingValidated contact frames and corrected motion so body weight read properly in playback.
Hip / shoulder offsetsAdjusted retarget results and checked silhouettes so the character did not feel mechanically shifted from the original performance.
Artist review bottleneckPrepared clean preview outputs and notes so review could focus on acting and motion quality.
