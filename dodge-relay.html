01 / Play

Use A / D for Pilot A and W / S for Pilot B. Hold the beam intersection over the moving signal for 0.25 seconds. Decoys reset your combo. One round = 60 seconds.

Practice works with one keyboard or two people.

02 / Peer-to-peer multiplayer

Test two clients instantly in two tabs using BroadcastChannel (same browser), or exchange WebRTC offer/answer codes between remote browsers. Host validates scoring and broadcasts the authoritative match state.

Fast test: open this page in two tabs, choose Host in tab 1 and Join in tab 2. This is a real two-client synchronization demo within one browser, no setup.

  1. Host creates an offer, sends the code to friend.
  2. Friend pastes offer, clicks Join, sends answer back.
  3. Host pastes answer, clicks Connect. Start playing.

Implementation boundaries. The browser demo implements local co-op, same-browser two-tab synchronization via BroadcastChannel, an optional WebRTC peer-to-peer connection path, host-authoritative scoring, 20 Hz state snapshots, client-side visual smoothing, a basic RTT probe, and disconnect handling. It is a prototype, not a released Meta Quest game. WebRTC connections may fail behind restrictive NATs without a TURN relay. The accompanying Unity/Netcode code is a separate development track and requires compilation, device profiling, and two-client validation before being described as tested VR multiplayer.
