What I owned

I directed the technical character pipeline across historical facial reconstruction, topology/UV, surface look, custom facial blendshapes, ARKit-to-Maya performance conversion, hair/beard, garment handoff, Unity HDRP lookdev, and kiosk compositing/interaction.

Approximately 256 total custom facial blendshapes — not “256 ARKit blendshapes.” Facial performance came first; a separate professional voice actor dubbed afterward. Hanbok cloth was simulated per shot in Marvelous and imported as Alembic, not simulated in real time in Unity.

TASK 01 / 06

Portrait → Historical Reconstruction

Problem
No living subject and no scan: only one historical portrait plus references.
Decision
Read the portrait as spatial evidence and infer plausible 3D volume without claiming forensic accuracy.
Implementation
ZBrush sculpt from portrait/history, analyzing angle and facial volume; heavy ZWrap use for production topology workflow.
Result
Historically grounded digital likeness suitable for animation.

TASK 02 / 06

Production Topology & Surface

Problem
The custom likeness had to survive retopo, UV, texture, rigging, and real-time rendering.

Keep the custom sculpt as identity source while rebuilding production topology/UV/surface.
Implementation
Retopology, fully rebuilt UVs, MetaHuman-derived/base skin reference in lookdev, direct skin/eye/normal tuning.

Custom Unity-ready character rather than a stock digital-human preset.

TASK 03 / 06

~256-Shape Facial Rig

Problem
The custom historical face needed expressive ARKit-driven animation without MetaHuman’s standard facial rig.
Decision
Build a large custom blendshape system.
Implementation
Approximately 256 total shapes expanded from primary expressions with mirrored, corrective, and combination shapes; iPhone/ARKit → CSV → Maya blendshape animation → bake.
Result
Custom facial-animation pipeline connected mobile capture to a bespoke face rig.

TASK 04 / 06

Hair, Beard & Hanbok

Problem
Portrait-specific hair/beard and layered hanbok needed controlled motion in Unity delivery.

Use authored hair/beard and per-shot offline cloth simulation.

Maya hair cards + beard; Marvelous Designer hanbok; simulate each shot; Alembic export; Unity Timeline sync; real-time secondary motion for hair/beard.

Historically specific appearance with controlled garment motion.

TASK 05 / 06

Unity HDRP Look Development

Problem
Custom skin, eye, hair and lighting had to feel human at museum viewing distance.
Decision
Tune the entire shading/lighting stack together.
Implementation
Skin SSS, roughness, normal/detail normal, specular, eye/cornea, hair shader, translucency, lighting, HDRI, color grading; adapted Unity Digital Human sample/project workflow to this custom character.

Cohesive real-time digital-human look in Unity HDRP.

TASK 06 / 06

Interactive Museum Kiosk

Problem
Visitors needed to appear with the character and trigger a pose, not just watch a render.
Decision
Composite live visitor camera feed and real-time character directly in the kiosk UI.
Implementation
WebCamTexture, RenderTexture, RawImage, camera-feed background, chroma/compositing, alpha character layer, touch button triggers V-pose.
Result
Public-facing interactive digital docent/photo experience.
