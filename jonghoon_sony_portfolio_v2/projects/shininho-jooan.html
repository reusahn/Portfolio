What I owned

I owned the downstream digital-human and performance pipeline: Maya scan cleanup, feasibility prototype, Wrap/MetaHuman conversion, texture and eye corrections, body/facial capture integration, mocap cleanup, Sequencer assembly, VR staging, lighting, and Niagara effects.

An external scan studio performed the original full-body volumetric capture. Do not imply that I operated the capture stage.

TASK 01 / 06

Scan → Real-Time Prototype

Problem
Heavy, asymmetric, hunched raw scan was not rig-ready.
Decision
Build a fast feasibility prototype first, accepting some likeness loss.
Implementation
Maya symmetry cleanup, reduction/retopology, local repairs, merge/smoothing, then AccuRIG for Unity.
Result
Validated feasibility and exposed likeness loss early.

TASK 02 / 06

Prototype → Production MetaHuman

Problem
The prototype worked but no longer preserved the grandmother’s likeness closely enough.

Return to the original high-resolution scan and rebuild around MetaHuman-compatible topology.
Implementation
Wrap face + body to MetaHuman-compatible topology/UV, then MetaHuman From Template.
Result
Substantially stronger likeness, detail, and animation quality.

TASK 03 / 06

Texture, Eye & Likeness

Problem
Scan texture and custom head created visible eye/scalp problems.
Decision
Keep scan identity data and fix only the failure points instead of rebuilding everything.
Implementation
Transfer face/body texture in Wrap; extend scalp in Photoshop; enhance wrinkle readability; tune eye position and iris appearance in Unreal.
Result
Preserved distinctive age/skin information while resolving visible eye mismatch.

TASK 04 / 06

Hybrid Performance Capture

Problem
Large dance motion, floor contact, finger detail, and facial headgear made one capture source unreliable.
Decision
Use complementary systems and select the strongest source by motion segment.
Implementation
OptiTrack/Motive for stable body motion, Move.ai for supplemental/finger motion, Rokoko + iPhone for facial capture, slate/clap for sync.
Result
Created recovery options for tracking failure and expressive close-ups.

TASK 05 / 06

Cleanup & Performance Assembly

Problem
Raw capture contained floating feet, ankle twist, arm spikes, and floor-contact loss.
Decision
Treat cleanup as reconstruction and editorial assembly.
Implementation
Maya/MotionBuilder filtering + manual reconstruction; separate body/face tracks in Sequencer; slate sync; choose best take combinations; bake final rig.
Result
Delivered a controllable final performance from imperfect capture.

TASK 06 / 06

Jooan — VR Extension

Problem
The same character had to work in 360° VR without camera discomfort or attention loss.
Decision
Keep viewer movement restrained; move the character; guide attention with light and controlled effects.
Implementation
Reduced camera speed after ~10 informal testers, Skylight + HDRI dusk look, Niagara system built from scratch with hand emitters and ribbon trails, tuned particle count for VR.
Result
Extended the digital-human pipeline into a comfort-aware VR staging system.
