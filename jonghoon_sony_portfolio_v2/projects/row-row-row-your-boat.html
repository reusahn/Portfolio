What I owned

I directly processed all ten MetaHuman identities and handled character lookdev, hair troubleshooting, performance timing, facial/body synchronization, ensemble staging, lighting variants, render stability, and final output preparation.

Capture source was depth video. Polycam was supplemental head capture only when the depth-video identity did not match well enough. Grooms were matched/tuned MetaHuman presets, not custom grooms from scratch.

TASK 01 / 06

10 Individual Identities

Problem
Ten different people had to pass through one repeatable character pipeline despite variable capture quality.
Decision
Use depth video as default; add Polycam head capture only where needed.
Implementation
MetaHuman Identity for all ten; Mesh-to-MetaHuman textures; per-person material, groom color, and body proportion tuning.
Result
Ten consistent, individually tuned digital humans.

TASK 02 / 06

Lookdev & Hair Stability

Problem
Skin/hair responded differently across characters; overlapping grooms created shadow noise, GPU cost, bounce, and flicker.
Decision
Tune each character independently while preserving one shared ensemble look.
Implementation
Three-point-style light; per-character hair roughness; deep shadow / hair width / density / ray settings; disable simulation where overlapping grooms flickered.
Result
Stable, readable ensemble across varied skin and hair.

TASK 03 / 06

Canon-Driven Staging

Problem
The musical round/canon needed a visual structure.
Decision
Make each vocal entrance trigger a spatial reveal.
Implementation
Two groups of five, intentional near-overlap, each character under an empty parent, parent scale animated from hidden/small to full at vocal entrance.
Result
Each new voice becomes a new visible face/body.

TASK 04 / 06

Mocap Reconstruction

Problem
Capture length/timing and transitions did not fully match the final musical edit; some motion popped or bounced.
Decision
Rebuild timing/editorial structure rather than treating raw capture as fixed.
Implementation
Copy/extend motion, retime, repair, Fourier-based filtering/processing, bake/reduction workflows.
Result
Completed performance timing despite incomplete original capture coverage.

Facial Capture & Control Rig

TASK 06 / 06

Lighting Variants & Delivery

Problem
Multiple front/side and morning/sunset/night variants had to render reliably with overlapping MetaHumans.
Decision
Rebuild HDRI/lighting per time-of-day; separate character/background passes when useful.
Implementation
New HDRI and lighting angle/reflection setup for every time; selected alpha character passes composited over separate backgrounds.
Result
Multiple stable visual variants for installation delivery.
