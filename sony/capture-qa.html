Capture Package QA

A lightweight Python tool makes the capture-to-DCC handoff contract explicit before a package reaches the next artist.

Scope

This prototype validates manifest metadata and source-file presence. It does not decode capture media, FBX, or Alembic and does not evaluate tracking, geometry, or animation quality. Included sources are clearly labeled synthetic text stand-ins.

The production problem.

A package can contain every expected filename and still arrive with the wrong frame rate, unit scale, axis convention, or timing assumptions. Those mismatches should be visible before an artist starts retargeting or a simulation department attempts to use the character.

The implemented contract.

InputImplemented checkReview output
Project, operator, subject and take IDsRequired fields and unique take IDsSpecific missing or duplicate field
Body / face source pathsPackage-relative paths, file presence and non-empty bytesMissing / empty source or rejected external path
Source frame rates and inclusive rangesPositive finite rates, integer ranges, sync events within boundsInvalid metadata or a source-to-destination resampling review
Common sync eventCalculate face timeline translation and aligned source coverageFace shift in seconds; low-coverage warning
Destination export specificationRate, units, up axis and full-character Alembic inclusionMismatch against the declared receiving specification

Make the timing convention inspectable.

The tool assumes the supplied sync frames identify the same event and are absolute source indices. It computes a translation for the face timeline:

face shift (seconds) = body sync frame / body fps − face sync frame / face fps

In the synthetic example, body frame 30 and face frame 45 are both declared at 30 fps. Moving the face timeline by −0.5 seconds aligns that event. This single-event alignment does not correct recording drift or judge performance synchronization.

Validation and limitations.

Twelve synthetic tests cover offsets and overlap, missing files, invalid frame rates including NaN / infinity, export mismatches, resampling review, duplicate takes, out-of-package paths, facial geometry declarations, and malformed input. These tests validate the packaging logic rather than a real capture production.

Run the sample.

python capture_package_validator.py sample_manifest.json --root . --output sample_report python -m unittest test_validator.py
