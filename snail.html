PRODUCTION METHOD

Investigate → measure → implement → validate.

I treat technical art as production engineering for visual content. The point is not only to make an asset work once, but to understand why it failed and turn the solution into a dependable workflow.

01Reproduce

Isolate the visual, asset, shader, integration, or runtime failure consistently.

02Inspect

Trace the issue through material state, geometry, transforms, animation, imports, and engine behavior.

03Profile

Check the relevant performance and complexity constraints before choosing a fix.

04Implement

Build the shader, tool, asset change, Blueprint / code path, or pipeline adjustment.

05Validate

Test the solution in the actual scene, device, character, lighting, or production context.

06Standardize

Document the decision and convert recurring work into a reusable standard or workflow.

Production principle: A technical-art fix is not finished when it works once. I validate it in the real scene or runtime context, document the decision, and turn recurring solutions into standards or reusable workflows whenever possible.
