# Daily A/B/C Review Dialogues — Creative Experiments

This directory archives the **actual daily simulated reviewer discussion and decisions** produced during each development cycle. Reviewers are fictional roles for structured critique:
- **A — Hiring reviewer:** Is the idea and evidence compelling and clearly communicated?
- **B — Hypothetical Creative, Experiments lead:** Does the interaction require a frontier model, demonstrate technical craft, and have an actionable production pathway?
- **C — AI arts reviewer:** What is artistically new, what does the medium communicate, and what ethical assumptions are embedded?

## Record every day a development cycle runs
Create a dated `YYYY-MM-DD.md` file in **America/Los_Angeles** and record:
1. **Source materials:** exact files and prior status examined.
2. **Reviewer A:** explicit critique in A's simulated voice, grounded in real work.
3. **Reviewer B:** explicit response to A and technical / creative critique.
4. **Reviewer C:** challenge to both from an artistic / ethical perspective.
5. **A → B → C discussion:** at least one genuine exchange, with disagreements and revisions; never claim real people spoke.
6. **Decision:** single agreed next step and dissent/unresolved issue.
7. **Completed work:** exact paths and commits; test *run* vs test *planned*; links to demos.
8. **Scores:** optional, only if tied to criteria and current proof. Never inflate score automatically.
9. **Tomorrow:** highest-priority task / blockers.

**Integrity:** This is a repository for **development-specific simulated discussions**, not a copy of all private ChatGPT conversations. Do not publish raw user chat transcripts, user-identifying details, private letters, credentials, undisclosed client information, or participant confessions. Do not fabricate a conversation that did not occur. When backfilling a past date, mark it as a retrospective summary derived from the logged work, not verbatim reviewer dialogue.

Also update [WORK_LOG.md](../WORK_LOG.md) and cross-reference the day's discussion. Daily scheduled runs are bounded attempts; a five-hour focus plan does not guarantee five elapsed hours of continuous autonomous work.
