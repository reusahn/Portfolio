## Bounded One Scene improvement
Added `one-scene/qa.mjs`: a zero-dependency Node command using `spawnSync` to syntax-check seven source/test modules, then execute the existing `tests.mjs` only if syntax passes. It forwards test output, signals nonzero failure, and explicitly distinguishes source QA from browser/model/human testing. This creates a repeatable QA entry point for a future network-enabled checkout; **it is not evidence of passing tests**. Updated `one-scene/README.md` with the command and limitation.
