## Editorial commitments
- Distinguish **facts**, **witness inference**, **AI-generated interpretation**, and **director-authored cinematic choices**.
- Do not fabricate user-study results, model evaluations, audience feedback or commercial releases.
- Do not expose API keys in GitHub Pages; use a server-side proxy if model calls are added.
- Protect visitors' personal disclosures and avoid impersonation or deceased-person voice cloning without relevant rights and consent.
- Make accessible captions, keyboard controls, reduced-motion options and a deterministic non-AI fallback.
