AI ZOO

An interactive Unity installation where AI dialogue, sensors, physical motion, voice, and lighting are synchronized into one real-time behavioral system.

Many systems, one runtime

AI ZOO coordinates audience input, AI dialogue, proximity sensing, servo motion, lighting, microphone / speaker interaction, and generated voice behavior. Unity acts as the real-time integration layer while C# and Python synchronize the different subsystems.

Audience Input ↓ AI / Emotion State ↓ Unity Runtime ↙ ↓ ↘ Servo Lighting Voice ↓ Audience Feedback ↓ Next Interaction State

Technical responsibilities

  • Unity runtime integration across AI, sensors, physical hardware, lighting, and voice.
  • C# and Python scripting for system coordination.
  • Distance-driven response intensity and lighting behavior.
  • Data logging of audience interactions for later behavioral visualization.

Pipeline relevance

The project trained the same habit I use in technical art: identify where a system can fail, isolate the interface between disciplines, make the runtime state observable, and turn an unstable prototype into something another person can actually use.
