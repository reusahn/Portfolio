Mobile Real-Time Character Pipeline

A focused Unity URP character test built to prove that animation, rigging, cloth, camera interaction, and performance behavior work as a real Android runtime rather than only as an Editor presentation.

Why this test matters

The goal was not another offline character render. The system had to continue behaving correctly while the user changed animation states, camera framing, cloth state, and character count on an Android build.

Character + animation pipeline

  • Prepared a CC4 character and costume for Unity.
  • Adjusted character and garment skin weights before runtime cloth.
  • Configured a Humanoid rig and integrated retargeted animation clips.
  • Built interactive ARGUE, DANCE, FIGHT, POINT, and TALK runtime states.
Character + Costume ↓ Skin-Weight Cleanup ↓ Humanoid Rig / Retargeting ↓ Unity Runtime Animation States ↓ Unity Cloth + Collision ↓ Touch Camera / Look-At / UI ↓ Android Build + Device Validation

Real-time cloth

The cape uses Unity Cloth rather than replaying a baked garment cache. Constraint regions, collision, skinning, stiffness, damping, and solver behavior were tuned so the same garment responds to multiple animations at runtime.

Platform proof

The final system was built as an Android APK and tested on-device. It also includes runtime camera controls, cloth controls, look-at behavior, and multi-character testing so the sample can be evaluated as an application rather than a captured Editor scene.
