Gang Se-hwang Digital Human

A custom historical digital human reconstructed from portrait evidence, prepared for facial performance, rendered in Unity HDRP, and delivered as an interactive museum experience.

ROLE Technical Director FOCUS Custom character asset Facial performance HDRP look development Interactive deployment

Custom asset to real-time application

The character was not a stock MetaHuman. Portrait-based reconstruction moved through custom topology and UV work, skin maps, hair cards, facial blendshapes, performance data, garment delivery, and final Unity HDRP implementation.

Unity-side work

  • HDRP skin, eye, hair, and lighting look development.
  • Facial animation using a custom blendshape system driven from ARKit-based performance data.
  • C# presentation logic for camera, UI, animation state, and interactive kiosk behavior.
  • Final installation deployment and presentation tuning.

Production decision-making

Different asset components used different representations based on the quality target. Hair remained a real-time card-based asset; the historical Hanbok used deterministic offline cloth caches when that produced a more convincing result than forcing every component into the same runtime solution.
