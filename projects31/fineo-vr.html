Fineo, Translated Universe

A VR installation that remaps periodic-table data into an explorable artificial universe, using harmonograph-based functions as a rule system for generating spatial structures.

World generation from rules

Fineo started from structured elemental data rather than a conventional environment-design brief. Numerical properties were translated into harmonograph-based visual rules, then assembled into a world the audience could navigate spatially.

Technical approach

  • Mapped elemental data into visual and spatial parameters.
  • Used harmonograph-based functions to create repeatable orbital and constellation-like structures.
  • Constructed the generated results as a navigable Unity VR environment.
  • Connected a data system, visual rule set, and immersive presentation rather than hand-authoring every final form.
Elemental Data ↓ Parameter Mapping ↓ Harmonograph-Based Rules ↓ Generated Spatial Structures ↓ Unity VR World ↓ User Navigation

Why this matters for VRChat

The project shows a systems approach to worldbuilding. Instead of treating every environment element as a unique manual task, a rule set produces coherent spatial content that can scale and vary while preserving the logic of the world.
