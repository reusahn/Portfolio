Escape Metro

A surreal Unity VR escape experience that uses real-time conversational NPC behavior as part of the gameplay and navigation loop.

UnityVRChatGPT APIInteractive Gameplay
ROLE Director / Technical Artist FOCUS VR interaction AI NPC behavior Runtime experience

Runtime content, not a linear scene

The player navigates an underground VR environment and interacts with conversational NPCs to progress. The project required spatial content, player interaction, dialogue state, and an external AI service to operate as one real-time experience.

Pipeline relevance

  • Unity-based VR environment and interaction design.
  • ChatGPT API-driven NPC conversation inside the runtime experience.
  • Technical integration between authored 3D content and dynamic behavior.
  • Iteration around user navigation, feedback, and spatial legibility.
3D Environment + NPC Content ↓ Unity Runtime Interaction ↓ Player Input ↓ AI Conversation ↓ NPC Response / Gameplay State ↓ VR User Experience

Why it maps to VRChat

The project sits at the same boundary that makes live social-world content difficult: visual assets only become useful once interaction, runtime state, user feedback, and platform behavior are dependable together.
