Escape Metro

A surreal VR escape game built as a playable Unity world, combining environment content, interaction logic, character animation, player voice, AI-driven NPC conversation, sound, and standalone-headset constraints.

A complete VR runtime, not a visualization

Escape Metro was structured around player agency inside a navigable subway world. The player moves through the environment, solves spatial problems, and communicates with an in-world AI character as part of progression.

My technical work

  • Built and integrated the Unity XR runtime and interaction flow in C#.
  • Prepared AI guard / NPC character assets for the Unity character pipeline.
  • Integrated facial expressions and blendshape-driven lip sync with Animator-driven character behavior.
  • Connected player voice input to speech-to-text and conversational AI response.
  • Integrated the psychological soundscape through FMOD and Unity Audio Mixer.
  • Adjusted shaders and baked lighting with standalone Meta Quest performance in mind.
Environment + Character Assets ↓ Unity XR Runtime ↓ Player Navigation / Interaction / Voice ↓ NPC Dialogue + Animation State ↓ Puzzle / Progression Logic ↓ Standalone Headset Experience

Why this matters for VRChat

This project is direct evidence of building an immersive world where art assets, interaction, characters, audio, and runtime state have to work together inside headset constraints. The work is much closer to live world-content production than to an offline cinematic pipeline.
