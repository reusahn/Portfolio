01 / PROBLEM & OWNERSHIP

A design problem translated into a runtime system.

The distinction between creative objective and technical contribution is central to this case.

Design / production challenge

Interactive digital-human presentation depends on more than a rendered character: timed events, loop transitions and responsive sequences must execute reliably without manual intervention. Artists need to revise the content without repeatedly altering low-level logic.

My technical contribution

I worked with Unreal Blueprint playback and event triggers, transition logic and Sequencer timing within the Shininho production pipeline. This is visual scripting for real-time character presentation, not a claim of a shipped game AI behavior tree.

02 / IMPLEMENTATION

How the feature works.

Concrete subsystems and boundaries, not only a list of software tools.
