UNITY / GRAPHICS SYSTEMS

Erick Oh — Confidential Real-Time Game

A production case focused on controllable real-time visual systems built in Unity URP, with custom HLSL rendering and C# runtime behavior.

ROLE Technical Artist / Technical Director (Contract) DATES 04/2025 - 04/2026 ENGINE Unity URP FOCUS HLSL · C# · runtime graphics

Problem

The project needed expressive real-time visual behavior that could respond to runtime state while remaining controllable enough for production iteration.

Implementation

  • Built an opaque mesh cloud using custom HLSL Perlin-based vertex displacement and Fresnel-based presentation.
  • Connected C# input to the shader's internal noise-flow direction rather than simply translating the GameObject.
  • Prototyped a raymarched metaball field while keeping rendering and gameplay collision / proximity logic as separate systems.
  • Built a deterministic four-state transformation system using fixed-topology Maya blendshape targets and Unity Timeline / Animation keyframes.
Runtime Input ↓ C# State / Parameters ↓ HLSL Shader Behavior ↓ GPU-Rendered Visual Response Gameplay collision logic remains separate from visual-field rendering.

Developer Relations Relevance

This case reflects the boundary debugging common in engine support: deciding whether a problem belongs to runtime logic, shader behavior, animation state, or interaction design, then explaining the technical tradeoff clearly enough for collaborators to act on it.
