Gang Se-hwang - Unity HDRP Interactive Character

A real-time Unity HDRP character application combining custom character production with C# camera presentation, UI, animation triggers, timing, and kiosk interaction.

ENGINE Unity HDRP ROLE Technical Artist / Developer CODE C# FOCUS UI · camera · interaction · character rendering

Implementation

  • Built and integrated the character, materials, hair, facial animation, clothing simulation handoff, lighting, and real-time presentation in Unity HDRP.
  • Implemented C# camera presentation, UI behavior, animation triggers, timing / media lengths, and interaction states.
  • Used direct camera background presentation with the digital human composited as part of the Unity experience; no green-screen workflow was used.

Pipeline Decisions

The character used custom facial blendshape work and an iPhone facial CSV to Maya workflow. A pre-existing GitHub Python importer was adapted to the production naming / case requirements rather than claimed as an original importer implementation.

Developer Relations Relevance

This project required both content-pipeline knowledge and application logic. It is representative of the support problems game developers encounter when rendering, animation, UI, input, and production constraints meet inside one engine project.
