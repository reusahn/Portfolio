Implementation

  • Integrated the character, materials, hair, facial animation, clothing simulation handoff, lighting, and real-time presentation in Unity HDRP.
  • Implemented C# camera presentation, UI behavior, animation triggers, timing / media lengths, and interaction states.
  • Used a direct camera background in the kiosk experience; no green-screen workflow was used.

Character / Facial Pipeline

The production used custom facial blendshape work and an iPhone facial CSV-to-Maya workflow. A pre-existing GitHub Python importer was adapted to the production's naming and case requirements rather than presented as an original importer implementation.
