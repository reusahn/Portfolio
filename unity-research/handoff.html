Context Gate.

A delayed placement hint can arrive after the user changes the board. The source compares delivering every well-formed hint with rechecking its object-state preconditions.

Proposed contribution: a Unity harness that records whether delayed hints were displayed, discarded, timed out, or cancelled across paired trials.

A small first collaboration

Choose one task-state contract and one target platform. First produce a reviewable desktop run of Context Gate. Then decide whether the same lifecycle should be bound to one lab interaction.

  • I would own: the Unity scene, state transition, response validation, event trail, and runbook.
  • We would choose together: task difficulty, the input adapter, valid-trial rules, and required timing precision.
