Unity / Python · Leap Motion · Arduino servos · LLM · Digital human · Voice / lighting

Leap Motion 손 입력과 실시간 LLM 대화를 Unity 디지털 휴먼, 생성 음성, Arduino 서보모터와 조명에 연결했다. Unity와 Python이 입력과 출력을 조율하는 인터랙티브 설치 작업이다.

Unity 구현

대화와 디지털 휴먼

실시간 언어 입력을 LLM 응답과 생성 음성으로 연결하고 Unity 캐릭터가 화면에서 응답하도록 구성했다. 대화 입력과 손 입력은 서로 다른 경로로 들어온다.

Leap Motion 손 입력

Leap Motion으로 관객의 손 움직임을 받아 설치 시스템의 입력으로 사용했다. 실제 장치가 전시 화면 옆에 놓인 모습은 작품 사진에서 확인할 수 있다.

Arduino 출력

디지털 시스템의 응답을 서보모터와 조명으로 확장했다. 기존 하드웨어 사진은 구체의 연결 구조를 보여주며, 명령 프로토콜과 모터 제한값은 별도의 원본 소스 확인이 필요하다.
