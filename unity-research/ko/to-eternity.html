To Eternity

2020

Azure Kinect · Unity Timeline · Live composition · C#

관객이 꽃을 쥔 손동작과 목표 제스처의 유사도가 87% 이상이면 Azure Kinect로 자동 촬영한다. Unity가 촬영된 인물 이미지 위에 실시간 사진 모자이크를 구성하고 Timeline으로 추모 시퀀스를 이어간다.

Unity 구현

꽃을 쥔 손동작과 자동 촬영

Azure Kinect로 꽃을 쥔 손의 제스처를 인식한다. 목표 손동작과의 유사도가 87% 이상이 되면 카메라가 관객의 사진을 자동으로 찍는다. 87%는 촬영 조건으로 설정한 유사도 기준이며, 인식 정확도 측정 결과를 뜻하지 않는다.

Unity Timeline

제스처를 만족하는 순간 촬영 이벤트가 발생한다. 이 입력을 Timeline의 추모 시퀀스와 화면 전환에 연결해 관객마다 시작 시점이 달라지도록 했다.

사진 위 실시간 모자이크

자동 촬영한 관객 사진 위로 사진 이미지가 실시간 모자이크로 쌓이며 추모 화면을 구성한다. 제스처 판정, 촬영, 모자이크와 재생 시퀀스는 구분되는 처리 단계다.
