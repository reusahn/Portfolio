# A–D 가상 편집 검토 / 전체 15개 작품

A는 웹사이트 디자이너 관점, B는 현재 요청에서 확인된 안종훈의 목표, C는 Four Eyes의 공개 연구에 근거한 관점, D는 HAX의 공개 연구에 근거한 관점이다. 아래 발언은 가상 검토다. Tobias Höllerer와 Misha Sra의 실제 평가나 발언이 아니다.

## 1. 전체 작업을 어떻게 보여줄 것인가

A: 세 작품만 크게 보여주고 나머지는 보조 링크에 두면 작업의 폭이 사라진다. 네 갈래의 이미지 카드와 검색을 사용하자.

B: 15개 모두 있어야 한다. 센서, 셰이더, 디지털 휴먼, 가상세계는 내 작업 안에서 연결된다. Escape Metro와 RedFlight는 하나로, NARCI와 Be NARCI는 연결된 사례로 세자.

C: 작품이 많아도 입력과 Unity 처리, 출력의 경계가 보여야 한다.

D: 각 기술이 어떤 인간의 행위와 관계를 만드는지 읽혀야 한다.

반영: 전체 15개 카드와 15개 상세페이지를 만들었다. 기본 화면에서는 모두 보이며, 모든 읽기 경로에서도 같은 15개 작품을 유지한다.

## 2. 어떤 기술을 바로잡을 것인가

B: 꽃과 파도는 VFX Graph와 셰이더다. 비즈월은 웹캠과 VFX Graph다. 투 이터니티는 Azure Kinect와 Timeline이고, 실학댄스와 Track 6는 Kinect v2다. 제물포는 Barracuda·스타일 변환·필터가 먼저 보여야 한다.

C: 센서 세대를 섞지 말자. Timeline의 시간과 라이브 센서 이벤트가 만나는 지점을 드러내자.

D: AI ZOO의 서보·손 인식·대화·디지털 휴먼을 하나의 연결된 만남으로 설명하자. 최정훈은 말이 얼굴과 음성의 수행으로 돌아오는 사례다.

A: 상세페이지에는 구체적으로 쓰고, 메인 카드에는 핵심 기술만 짧게 남기자.

반영: 이번 사용자 설명을 우선했다. Systems 페이지에 15개 작품의 입력·기술·출력을 비교했다. 제물포의 네트워크 예제는 이미지 변환 사례를 보완하는 위치로 이동했다.

## 3. 피네오의 중심은 무엇인가

B: 피네오는 기술보다 컨셉이 더 중요한 작품이었다.

D: 주기율표를 VR에서 보여주는 데서 끝나지 않는다. 데이터가 하모노그래프 형상이 되고 더 큰 관계를 이루며, 사람이 그 질서 안에 들어간다는 번역의 개념이 중심이다.

C: 실제 매핑과 원본 구현을 확인할 지점은 남기자. 오래된 방정식과 하드웨어 목록을 검증된 생산 코드로 옮기지는 말자.

A: 제목, 개념 문장, 실제 VR 사진을 먼저 둔다. 협업 크레딧도 자연스럽게 적자.

반영: 구성된 물질 세계라는 발상을 중심으로 상세페이지를 작성했다. Geum Jaesung, Jonghoon Ahn, Yu Hwanjun의 협업을 표시했다. 원자 물리의 정확한 시뮬레이션이나 학습 효과를 주장하지 않았다.

## 4. 철학·프리프로덕션·연구의 관계

D: NARCI는 성찰과 자기 회복의 의도를 가진 VR 경험이다. 치료 효과를 검증한 결과로 쓰지 않는다. Graffiti는 현실의 흔적과 공간 권한을 가상에서 다시 생각하게 하고, Escape Metro는 제약을 협상하는 행위가 퍼즐이다.

C: 작품마다 조작 가능한 차이를 하나씩 제안하자. 연구 결과처럼 쓰지 않는다. 새 연구 프로토타입은 Context Gate 하나를 유지한다.

B: 구상과 제작 판단을 보여주되 없는 과거 기획서를 만들지는 말자.

A: 새로 쓴 회고적 설계 노트라는 짧은 표시로 충분하다. 본문은 작품 자체에 집중하자.

반영: 각 사례에 질문, 개인 구현, 시스템 흐름, 세 개의 개발 판단, 연구 질문과 비교 조건을 넣었다. Approach와 별도 개발 노트 문서도 작성했다.

## 5. 실제 화면에서의 검토

A: 첫 화면의 15개 노출, 검색, 초기화, 결과 없음, 상세 이동을 확인하자. 모바일 폭에서도 읽혀야 한다.

B: 작품을 빼서 화면 문제를 해결하지 않는다. 기존 홈페이지와 회사 지원용 페이지도 보존한다.

C: 브라우저 동작과 Unity 실행은 별도다. 원본 런타임과 Inspector를 다음 증거로 지정하자.

D: 체험의 의도, 실제 구현, 연구 가설과 측정 결과를 나눠 읽을 수 있어야 한다.

확인: 데스크톱에서 전체 15개, 분류·검색·초기화를 검수했다. Kinect v2는 실학댄스와 Track 6, raymarching은 Erick Oh, Barracuda는 제물포로 연결됐다. 390px iframe에서 모바일 CSS와 검색을 확인했고 가로 내용 넘침이 없었다. Fineo 상세페이지와 Vimeo 재생을 확인했다. 실제 모바일 기기나 모든 영상에 대한 전수 검증은 아니다.
