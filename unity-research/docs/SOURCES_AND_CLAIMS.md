## Evidence hierarchy

1. The user's current, explicit description establishes intended scope and corrects older descriptions.
2. Existing portfolio / repository documentation supports documented mechanisms and project media.
3. Source files or execution records are needed for implementation-level verification.
4. Newly authored independent examples illustrate principles. They do not prove the original implementation used the same design.

The inspected Unity-Unreal-Interaction-Research tree contained documentation and media, not original C# or shader source. The inspected UnityXRPortfolio tree was also a portfolio archive. Original project code was therefore not audited.

Existing technical documentation:

### Jemulpo Photo Studio

Owner confirms Unity / Python / OpenCV, TCP/UDP, and up to four simultaneous participants.

- https://jonghoonahn.com/detail_pages/interactive_3.html
- https://jonghoonahn.com/thatgamecompany-jemulpo.html
