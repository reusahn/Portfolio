03 / Production handoff — three performers

When It Seen

Separate body and facial capture streams brought into coherent Unreal animation and exported for Houdini cloth simulation.

Role: Motion Capture Specialist · Synchronization and downstream handoffStack: MOVIN TRACIN · Rokoko · iPhone facial capture · Unreal Engine · Alembic · Houdini
01 / Production challenge

Why this work was hard

Three performers were captured using independent body and facial workflows. Those asynchronous data sources needed alignment and deformation checks before the animation could become reliable input for downstream cloth-contact simulation.

02 / Technical responsibility

What I built and integrated

I integrated body and facial takes per performer, aligned them in Unreal, inspected timing and deformation, and prepared full-character animated Alembic deformation caches for the Houdini team. This made the engine validation and DCC handoff explicit steps instead of relying on unreviewed raw capture.

03 / Implementation sequence

From source to reviewable character

01 Ingest per-performer sources

Track distinct body motion and face performance sources for each of three characters.

02 Synchronize

Align source timing and facial/body playback for coherent performance.

03 Validate in Unreal

Check visible timing, deformation behavior, and the combined character before baking.

04 Bake full-character animation

Produce an animated deformation output suitable for downstream processing.

05 Deliver Alembic to FX

Pass complete character caches to Houdini for cloth-contact simulation.

06 / Reviewable engineering decisions

What the pipeline taught me

Independent captures need a common timeline

Body and face recorded separately should not be assumed to start or end at identical times.

Verify before destructive handoff

Review integrated motion in Unreal before baking out to a downstream format.

Define the receiving team

A successful exporter is not enough; the cache must be usable by the cloth-simulation workflow.

Evidence boundary

The documentation supports animation synchronization, Unreal review and Alembic handoff. It does not establish that this project used a reusable gameplay Animation Blueprint, live networking, or Unity character-runtime logic.
